## 1. 用語集

### 1-1. 商品・スキーム

| 用語 | 意味 | 章 |
| --- | --- | --- |
| **MMF** | マネー・マネジメント・ファンド。短期の公社債等で運用する公社債投資信託。日々決算・月末一括再投資が特徴 | [①](01-overview.md) |
| **MRF** | マネー・リザーブ・ファンド。証券総合口座の待機資金を自動で運用する仕組み。MMFより自動性が高い | [①](01-overview.md) |
| **公社債投資信託** | 約款上、株式を組み入れないことになっている投資信託。**株式投信とは課税区分が異なる** | [①](01-overview.md)・[⑪](11-tax-nisa-account.md) |
| **追加型** | いつでも買い増しできるタイプ | [①](01-overview.md) |
| **日々決算型** | 毎営業日に決算し、分配金を計上するタイプ | [⑤](05-distribution-reinvestment.md) |
| **実績分配型** | 運用実績に応じて分配する（予定利率がない） | [①](01-overview.md) |
| **委託会社** | ファンドを設定し運用する会社（運用会社）。委託者 | [⑦](07-management-company.md) |
| **受託会社** | 信託財産を保管・管理する信託銀行。受託者 | [⑨](09-trustee-settlement.md) |
| **販売会社** | 顧客に販売する金融機関。**本件では自社** | — |
| **受益者** | ファンドの持分を保有する顧客 | — |
| **信託約款** | ファンドの基本的な取り決めを定めた文書。**商品性の最終的な根拠** | [⑦](07-management-company.md) |
| **繰上償還** | 信託期間の満了前に償還すること | [⑬](13-compliance-ops.md) |
| **ブレーク・ザ・バック** | 元本の安定を目指すファンドで元本割れが生じること | [⑬](13-compliance-ops.md) |

### 1-2. 取引・計算

| 用語 | 意味 | 章 |
| --- | --- | --- |
| **基準価額** | ファンドの1口あたりの価値。MMFでは**1万口あたり**で表示するのが通例 | [④](04-order-correction-cancel.md) |
| **未収分配金** | 日々計上されたが、まだ再投資されていない分配金の累計 ★MMF固有 | [⑤](05-distribution-reinvestment.md) |
| **月末一括再投資** | 当月の分配金を月末最終営業日にまとめて再投資し、口数を増やす処理 | [⑤](05-distribution-reinvestment.md) |
| **信託財産留保額** | 短期間で解約した場合に差し引かれる金額。信託財産に留保される | [④](04-order-correction-cancel.md) |
| **ロット管理** | 取得日ごとに口数を管理すること。信託財産留保額の期間判定に必要 | [④](04-order-correction-cancel.md) |
| **カットオフ（締め時刻）** | 当日扱いとする注文の受付期限 | [④](04-order-correction-cancel.md) |
| **約定** | 取引が成立すること。基準価額が確定して数量・金額が決まる | [④](04-order-correction-cancel.md) |
| **受渡** | 資金と受益権が実際に移動すること | [④](04-order-correction-cancel.md)・[⑨](09-trustee-settlement.md) |
| **アボート＆リブック** | 元の注文を取り消し、正しい内容で新規に入れ直す訂正方式 | [④](04-order-correction-cancel.md) |
| **事故訂正** | 受渡完了後に誤りが発覚し、事後的に修正すること | [④](04-order-correction-cancel.md) |
| **冪等性（べきとうせい）** | 同じ処理を複数回実行しても結果が1回分になる性質。二重発注防止に必須 | [④](04-order-correction-cancel.md) |
| **ネッティング** | 買付と解約を相殺し、差額のみを決済すること | [⑨](09-trustee-settlement.md) |
| **リコンサイル（残高照合）** | 自社の記録と相手方の記録を突き合わせること | [⑨](09-trustee-settlement.md) |
| **7日間平均利回り** | 直近7日間の分配実績を年率換算した指標。MMFの主要な比較指標 | [⑧](08-info-vendor.md) |

### 1-3. 税務

| 用語 | 意味 | 章 |
| --- | --- | --- |

| **譲渡所得等** | 解約・償還時の差益が区分される所得 | [⑪](11-tax-nisa-account.md) |
| **特定口座** | 証券会社が損益計算を代行する口座。源泉徴収あり／なしがある | [⑪](11-tax-nisa-account.md) |
| **損益通算** | 利益と損失を相殺すること | [⑪](11-tax-nisa-account.md) |
| **取得単価** | 税務上の譲渡損益を計算するための1口あたり取得価額 | [⑪](11-tax-nisa-account.md) |
| **NISA** | 少額投資非課税制度。★**公社債投信は対象外**という整理 | [⑪](11-tax-nisa-account.md) |
| **年間取引報告書** | 特定口座の年間の取引をまとめて交付する書類 | [⑪](11-tax-nisa-account.md) |

## 4. 統合チェックリスト

- [ ] コンプライアンスへ適用法令の一覧作成を依頼した（[⑬](13-compliance-ops.md)）
- [ ] ★**日付シフトテストの可否**を確認した（[⑭](14-test-release.md)）
- [ ] ★**ソナーのリリース枠**を確認した（[⑩](10-sonar-integration.md)）

### 5-1. 管理表のフォーマット

## 7. 本ガイドの使い方（再掲）

> ⚠️ **本ガイドは要件定義の「たたき台」です。**
> - 法令・税制・自主規制ルールは改正されます。**記載内容を設計の根拠にせず、各章の「🔍 確認事項」を所管部門・専門家に確認してください**
> - ソナーの機能仕様については内部情報を持ちません。**すべて大和総研への確認が必要です**
> - 商品性は**信託約款**が最終的な根拠です。約款と異なる実装は、どれだけ合理的に見えても誤りです
>
> **本ガイドの価値は、「何を確認すべきか」のリストにあります。** 確認した結果を要件定義書に転記し、その根拠（誰が・いつ・何と回答したか）を必ず残してください。
