# ⑮ 口座種別・チャネル別の取扱い — 個人・法人・IFA口座の違い

[← ⑭ テスト・移行・リリース](14-test-release.md) ｜ [総合インデックス](README.md) ｜ 次 → [用語集・チェックリスト](glossary.md)

[⑪ 口座・税制・NISA](11-tax-nisa-account.md) では「MMFの課税は株式投信と違う」という軸で整理しました。本章は **「誰の口座か」で何が変わるか** という軸で、個人・法人・IFA経由をそれぞれ掘り下げます。

> ⚠️ **本章の前提（重要）**
> 税率・課税区分・非課税の要件は改正され、また個別の事情により取扱いが異なります。
> **本章に記載した税率・区分は「論点の所在を示す参考値」であり、設計の根拠にしないでください。**
> 必ず **税務部門または税理士の確認を取り、その回答を要件定義書に根拠として明記** してください。[9節の質問票](#9-税務部門への追加質問票)をそのまま使えます。

---

## 0. この章のゴール

1. **「口座区分」と「源泉徴収」は別の話**という、最も誤解されやすい点を解消する
2. 法人の源泉徴収がどうなるか、**システム対応外で発生しうる論点**は何かを把握する
3. **法人を一括りにできない**（源泉徴収の扱いが異なる法人類型がある）ことを理解する
4. IFA口座について、税務・業務・システムの各面での違いを設計できる

---

## 1. 【最重要】「一般口座だから源泉徴収なし」は誤り

この誤解が、設計で最も大きな事故を招きます。

### 1-1. 2つの「源泉徴収」を分けて考える

```
  MMFで発生する課税イベントは2つ。それぞれ源泉徴収の仕組みが違う。

  ┌─────────────────────────────────────────────────────────┐
  │ ①【分配金】＝ 利子等                                       │
  │                                                           │
  │   支払時に源泉徴収される                                   │
  │   ★口座区分（特定／一般）に関係なく、支払者が徴収する       │
  │   ★法人であっても徴収される                               │
  │                                                           │
  │   → つまり「一般口座だから税引前で受け取る」ことはない      │
  ├─────────────────────────────────────────────────────────┤
  │ ②【解約・償還の差益】＝ 譲渡所得等                         │
  │                                                           │
  │   特定口座（源泉徴収あり） → 口座内で源泉徴収される         │
  │   特定口座（源泉徴収なし） → 源泉徴収されない（要確定申告）  │
  │   一般口座               → 源泉徴収されない（要確定申告）  │
  │   法人                   → 源泉徴収されない（法人税で処理） │
  │                                                           │
  │   → ここが「特定口座の源泉徴収あり／なし」の意味            │
  └─────────────────────────────────────────────────────────┘
```

> ⚠️ **「特定口座の源泉徴収あり／なし」は、主に②（譲渡損益）の話です。**
> ①（分配金）は、口座区分にかかわらず源泉徴収されます。
> **したがって、ご質問の「法人は一般口座になるが、分配金は税引き後になるか」への答えは、「はい、税引き後になります」** という整理になります（★税務部門に確認してください）。

### 1-2. 再投資への影響

[⑤ 4節](05-distribution-reinvestment.md#4-源泉徴収と再投資の順序)の処理順序は、**法人・一般口座でも同じ**です。

```
  分配金（税引前）
       ↓
  源泉徴収            ← ★法人でも一般口座でも、ここは発生する
       ↓
  税引後金額で再投資   ← 増加口数は税引後の金額から計算される
```

**つまり、口座種別によって「再投資される金額」が変わります。** 税率が違えば、同じ保有口数でも増える口数が違います。この点を[⑭](14-test-release.md)のテストケースに必ず入れてください。

## 2. 個人と法人の違い（一覧）

| 論点 | 個人 | **法人** |
| --- | --- | --- |
| **特定口座** | 利用できる | ★**利用できない**（特定口座は居住者である個人が対象） |
| 口座区分 | 特定口座／一般口座 | ★**一般口座のみ** |
| **分配金の源泉徴収** | される | ★**される** |
| **源泉徴収の内訳** | 所得税＋復興特別所得税＋**住民税（利子割）** | ★**所得税＋復興特別所得税のみ**（[3節](#3-法人の源泉徴収)） |
| 解約差益の源泉徴収 | 特定口座（源泉あり）のみ | されない |
| 損益通算 | 上場株式等の枠内で通算 | 法人税の計算に取り込む（通算という概念がない） |
| 確定申告 | 口座区分・選択による | **法人税の申告**で処理 |
| **源泉所得税の扱い** | 納税の完結 or 申告で精算 | ★**所得税額控除**として法人税から控除（[3-3節](#3-3-所得税額控除への対応)） |
| NISA | 対象外（MMFの場合） | 制度の対象外 |
| 年間取引報告書 | 特定口座のみ作成 | ★**作成対象外** |
| 交付する通知書 | 個人向け様式 | ★**法人向け様式**（[③](03-internal-documents.md)・[②](02-customer-documents.md)） |
| マイナンバー | 個人番号 | **法人番号** |
| 適合性確認 | 必要 | 特定投資家（プロ）の扱いを含め要整理 |

## 3. 法人の源泉徴収

### 3-1. 何が引かれるか

> 🔍 **以下は参考値です。必ず税務部門に確認してください。**

| 区分 | 所得税 | 復興特別所得税 | 住民税（利子割） | 合計 |
| --- | --- | --- | --- | --- |
| **個人** | 15% | 0.315% | **5%** | **20.315%** |
| **法人** | 15% | 0.315% | ★**なし** | ★**15.315%** |

**「ソナーからは所得税だけが引かれるのでよいか」というご質問への答え**

> ✅ **法人については、「所得税＋復興特別所得税のみが源泉徴収され、住民税（利子割）は課されない」という整理が一般的です。**
>
> 背景：**法人に係る道府県民税の利子割は、2016年（平成28年）1月1日以降、廃止**されています。それ以前は法人にも利子割が課されていましたが、現在は法人に対する源泉徴収は所得税（＋復興特別所得税）のみ、という整理です。
>
> 🔍 **確認事項（必須）**
> 1. 現行制度において、**法人が受け取る公社債投資信託の収益分配金に対する源泉徴収の内訳と税率**
> 2. 個人の住民税（利子割）の特別徴収について、**販売会社が徴収・納入の義務を負うか**（[5節](#5-個人の住民税利子割の特別徴収)）
> 3. 上記の税率が、将来の税制改正でどう変わりうるか（[⑪ 8節](11-tax-nisa-account.md#8-税制改正への追随)の「税率をハードコードしない」設計に反映）

### 3-2. システム上の要件

| 要件 | 内容 |
| --- | --- |
| **税率の出し分け** | ★顧客属性（個人／法人）で源泉徴収税率を切り替える |
| **税額の内訳保持** | 所得税・復興特別所得税・住民税を**分けて保持**する（合算のみだと納付・帳票で困る） |
| 納付先の区分 | 所得税は国、住民税は都道府県。**納付先が違うため、集計を分ける必要がある** |
| 帳票の表示 | 法人向け帳票では住民税の欄をどう扱うか（0円表示か非表示か） |
| 再投資額 | 税引後金額で再投資（税率が違えば増加口数も違う） |

> 🔍 **大和総研へ（[⑩](10-sonar-integration.md)の質問23を補強）**
> - ソナーは、顧客属性（個人／法人）に応じて**源泉徴収税率を自動で切り替え**ますか
> - 源泉徴収税額を**所得税・復興特別所得税・住民税に分けて保持**しますか
> - 法人顧客に対する帳票の様式は、個人と別に用意されていますか

### 3-3. 所得税額控除への対応

法人は、源泉徴収された所得税を **法人税の申告で控除（所得税額控除）** できます。そのために、**顧客（法人）側は源泉徴収税額を正確に把握する必要があります。**

| 要件 | 内容 |
| --- | --- |
| **源泉徴収税額の通知** | ★法人顧客が申告で使えるよう、税額を明示した書類を交付する |
| 通知の様式・タイミング | 都度か、期間集計か。**法人の決算期は会社ごとに異なる** |
| **任意の期間での集計** | ★法人顧客から「当社の事業年度分の源泉税額を出してほしい」と依頼されうる |
| 再発行 | 申告時期に依頼が集中しうる |

> ⚠️ **「法人の決算期は3月とは限らない」という点に注意してください。** 個人のように「1月〜12月」で固定できません。**任意期間での源泉税額の集計・出力**ができないと、法人顧客からの依頼に手作業で対応することになります。
> 🔍 **大和総研へ**：法人顧客向けに、**任意期間を指定した源泉徴収税額の集計・出力**は標準機能で可能ですか。

## 4. 【重要】「法人」を一括りにできない — 源泉徴収の取扱いが異なる類型

ご質問の **「システム対応外で特別な税徴収はあったりするか」** に対する、最も実務的な答えがここです。

**「特別な税が追加で徴収される」というより、「そもそも源泉徴収されない／非課税になる法人類型が存在する」** という方が、要件定義上の論点としては重要です。

### 4-1. 想定される類型

> 🔍 **以下はすべて「確認すべき論点」です。適用の有無・要件は必ず税務部門に確認してください。**

| # | 類型 | 想定される取扱い | 要件定義への影響 |
| --- | --- | --- | --- |
| **1** | **公共法人等**（国、地方公共団体、法令で定める公共法人等） | 利子等が**非課税**とされる制度がある | ★**源泉徴収しない**区分の管理が必要 |
| **2** | **金融機関等**（銀行・信用金庫・保険会社等） | 一定の要件のもとで**源泉徴収が行われない**特例がある | ★同上。**所定の申告書の受理・管理**も伴いうる |
| **3** | **公益法人等・人格のない社団等** | 一般の法人と取扱いが異なりうる | 要確認 |
| **4** | **年金基金・共済等** | 非課税とされる場合がある | 要確認 |
| **5** | **外国法人** | 税率が異なる／**租税条約による軽減**の適用がありうる | ★届出書の受理・税率の個別設定が必要 |
| **6** | 投資事業組合・信託等 | 導管的な扱いとなる場合がある | 要確認 |

### 4-2. これが意味すること

```
 【設計上の分岐】

  法人口座を受け入れる
        ↓
  ┌─────────────────────────────────────┐
  │ すべての法人類型を受け入れるのか？      │
  └─────────────────────────────────────┘
        ↓
  ┌──────────────┬──────────────────────┐
  │ YES           │ NO                    │
  ├──────────────┼──────────────────────┤
  │ ★非課税区分・  │ ★スコープで明示的に   │
  │  源泉不適用の  │  除外する             │
  │  管理機能が必要 │  （一般の普通法人のみ）│
  │               │                       │
  │ ★申告書・届出書 │ ★受入時のチェック機能 │
  │  の受理・管理  │  が必要               │
  │               │                       │
  │ コスト：大     │ コスト：小            │
  └──────────────┴──────────────────────┘
```

> 💡 **第1フェーズの推奨**：**「一般の普通法人のみ」に限定**し、非課税法人・金融機関等・外国法人は明示的にスコープ外とする。
> ただし、**「スコープ外にする」ことと「受け入れてしまわないようにする」ことは別**です。口座開設時または買付時に、対象外の法人類型を弾く仕組みが必要です。これがないと、**誤って受け入れた後に「源泉徴収すべきでなかった」「税率が違った」という事故訂正**（[④ 6節](04-order-correction-cancel.md#6-受渡後の誤り事故訂正)）になります。

> 🔍 **確認事項**：自社が**現在どの法人類型の口座を保有しているか**を調査してください。既に非課税法人や金融機関の口座があるなら、「スコープ外」にはできません。既存の他商品でどう処理しているかを確認するのが最短です。

## 5. 個人の住民税（利子割）の特別徴収

法人側で「引かれない」ことの裏返しとして、**個人側では住民税が引かれる**という点も設計対象です。

| 論点 | 内容 |
| --- | --- |
| **徴収の主体** | 支払者（販売会社）が特別徴収する仕組み |
| **納入先** | 都道府県。★**所得税（国）とは納付先が異なる** |
| **納入期限** | ★法令で定められた期限。月末再投資で発生した分の期限管理（[③ 3節](03-internal-documents.md#3-経理会計帳票)） |
| **集計** | 所得税と分けた集計が必要 |
| **非居住者** | 住民税の扱いが異なる |

> ⚠️ **月末一括再投資は、全個人顧客の源泉税が一度に発生するイベントです。** 所得税と住民税を分けて集計し、それぞれの納付期限を管理する業務フローが必要です。[⑬ 5節](13-compliance-ops.md#5-日次オペレーション手順)の月末作業に含めてください。

## 6. 外国税額の論点（ファンド内で発生するもの）

「システム対応外で特別な税徴収があるか」という観点で、もうひとつ確認すべき論点です。

| 論点 | 内容 |
| --- | --- |
| **ファンド内での外国税** | ファンドが外国の資産を組み入れている場合、信託財産のレベルで外国税が課されることがある |
| 販売会社の対応 | ★これは**信託財産内の話**で、顧客への源泉徴収とは別。販売会社のシステムでは通常扱わない |
| **外国税額控除の通知** | ★ファンドによっては、顧客が外国税額控除を受けるための通知が必要になる場合がある |
| 円建てMMFの場合 | 国内の短期公社債等が中心なら、該当しにくい |
| 外貨建MMFの場合 | 該当しうる。また**為替差損益**の課税が加わる |

> 🔍 **確認事項（委託会社へ）**：当該ファンドについて、**外国税額控除に係る通知の要否**があるか。ある場合、委託会社から販売会社へどのデータが提供され、販売会社が顧客へ何を交付する必要があるか。
> 💡 **円建てで国内債券中心のMMFであれば、該当しない可能性が高い**です。ただし運用方針次第なので、[⑦ 3-5節](07-management-company.md#3-5-運用リスク)の確認事項に加えてください。

## 7. IFA口座（金融商品仲介業者経由）

### 7-1. 仕組みの整理

```
  ┌──────────┐  勧誘・媒介   ┌──────────────────┐
  │   顧客    │ ←──────────→ │ IFA               │
  │           │               │（金融商品仲介業者）│
  └─────┬────┘               └─────────┬────────┘
        │                              │ 所属
        │ ★口座は証券会社に開設          │ （証券会社が監督責任を負う）
        │   資産も証券会社が管理          │
        ▼                              ▼
  ┌────────────────────────────────────────┐
  │        証券会社（自社）                  │
  │        ＝所属金融商品取引業者            │
  └────────────────────────────────────────┘
```

**重要な前提**
- 顧客の口座は **自社（証券会社）に開設** される。IFAは顧客資産を預からない
- したがって **口座の名義人は顧客本人**（個人または法人）
- 自社は所属金融商品取引業者として、**仲介業者を監督する責任**を負う

### 7-2. 税務上の違い → **ない**

> ✅ **IFA経由であることによる課税関係の違いはありません。**
> 課税は**顧客が個人か法人か**で決まります。IFA経由の個人顧客は個人の扱い、IFA経由の法人顧客は法人の扱いです。
>
> **したがって、IFA口座のために税計算ロジックを追加する必要はありません。** ただし、次節の業務・システム上の違いは多数あります。

### 7-3. 業務・システム上の違い（12項目）

| # | 論点 | 内容 | 章 |
| --- | --- | --- | --- |
| **1** | **IFAコードの紐付け** | 口座にIFA（および担当外務員）を紐付ける。★新商品でも同じ仕組みに乗るか | [⑩](10-sonar-integration.md) |
| **2** | **注文経路** | IFA専用端末／IFAからの電話／顧客自身のWeb。★**どの経路を認めるか** | [④](04-order-correction-cancel.md) |
| **3** | **手数料シェア** | 代行手数料の一部をIFAへ支払う。★計算・支払・明細の仕組み | [③](03-internal-documents.md) |
| **4** | **IFA向け帳票** | 担当顧客の残高一覧、取引明細、手数料明細 | [③](03-internal-documents.md) |
| **5** | ★**目論見書交付の責任分担** | IFAが対面で交付するのか、自社がWebで交付するのか。★**交付記録をどちらが残すか** | [⑥](06-prospectus-delivery.md) |
| **6** | **適合性確認の責任分担** | 誰が確認し、誰が記録を保持するか | [⑫](12-web-nonfunctional.md) |
| **7** | **電子交付の同意** | IFA経由顧客の同意をどう取得・管理するか | [⑥](06-prospectus-delivery.md) |
| **8** | **勧誘記録** | IFAの勧誘記録の作成・保存・提出 | [③](03-internal-documents.md) |
| **9** | **苦情の一次受付** | IFAが受けるか、自社が受けるか。★エスカレーション経路 | [⑬](13-compliance-ops.md) |
| **10** | **モニタリング** | 所属業者としてIFAの営業行為を監督する。★MMFの短期売買等 | [③ 4節](03-internal-documents.md#4-コンプライアンスモニタリング帳票) |
| **11** | **IFAへの商品情報提供** | 新商品の案内、研修、販売用資料の提供 | [⑬](13-compliance-ops.md) |
| **12** | **KPI** | IFA別の残高・販売額・純流入 | [③ 6節](03-internal-documents.md#6-経営管理kpi) |

> ⚠️ **項目5（目論見書交付の責任分担）が最重要です。**
> 「IFAが対面で説明したから交付済み」とするのか、「自社のWeb上での交付をもって交付済み」とするのかで、**交付記録の持ち方が変わります**。ここが曖昧なまま運用すると、**「誰にも交付されていない」状態で買付が成立**しかねません。
> [⑥ 8節](06-prospectus-delivery.md#8-責任分界点)の責任分界点表に、**IFA経由の列を追加**してください。

### 7-4. MMF特有の事業性の論点

> 💡 **MMFは、IFAチャネルとの相性を事前に検討する価値があります。**
>
> | 要因 | 影響 |
> | --- | --- |
> | **ノーロード**（申込手数料なし） | IFAが受け取る販売時手数料がない |
> | **信託報酬が低い** | 代行手数料も低く、**IFAへのシェア原資が小さい** |
> | 短期保有されやすい | 残高が積み上がりにくい |
> | 一方で… | **「待機資金の置き場」として提案しやすく、他商品への導線になる** |
>
> **要件定義上の判断**：IFAチャネルでの取扱いを**第1フェーズに含めるか**。含めない場合、IFA経由の口座では買付できないよう制御する必要があります（★「何もしなければ買えてしまう」ことに注意）。

> 🔍 **確認事項**：企画部門に対し、**IFAチャネルでの取扱い方針**（含める／含めない／第2フェーズ）を確認してください。含める場合は、**手数料シェアの料率と計算方法**を決める必要があります。

## 9. 税務部門への追加質問票

[⑪ 10節](11-tax-nisa-account.md#10-税務部門への質問票)の20項目に加えて、本章の論点を確認してください。

### A. 法人の源泉徴収

1. **法人**が受け取る公社債投資信託の収益分配金について、**源泉徴収される税目と税率**を教えてください
2. 法人に対して、**住民税（利子割）は課されない**という理解で正しいですか
3. 法人の場合も、**分配金は税引後の金額で再投資**されるという理解で正しいですか
4. 法人は**特定口座を利用できない**（一般口座のみ）という理解で正しいですか

### B. 法人の類型による違い

5. **公共法人等**が受け取る利子等について、非課税とされる制度はありますか。ある場合の要件と、販売会社が行うべき手続は何ですか
6. **金融機関等**が受け取る利子等について、源泉徴収が不適用となる特例はありますか。ある場合の要件と、受理・管理すべき書類は何ですか
7. **公益法人等・人格のない社団等・年金基金**について、一般の普通法人と異なる取扱いはありますか
8. **外国法人**の場合の税率と、租税条約の適用手続を教えてください
9. 上記の類型を受け入れる場合、販売会社として**どのような区分管理と書類管理**が必要ですか

### C. 個人の住民税

10. 個人の**住民税（利子割）**について、販売会社は特別徴収義務者として徴収・納入する必要がありますか
11. その場合の**納入先と納入期限**を教えてください
12. 所得税と住民税を分けて集計・納付する必要がありますか

### D. 法人顧客への通知

13. 法人顧客が**所得税額控除**を受けるために、販売会社が交付すべき書類は何ですか
14. 法人の**決算期は会社ごとに異なる**ため、任意期間での源泉税額の集計・通知が必要になりますか
15. 法人顧客に対する**法定調書**の提出義務はありますか

### E. 外国税額

16. 当該ファンドについて、**外国税額控除に係る通知**が必要になる可能性はありますか

### F. IFA

17. **IFA経由の口座**について、課税関係に違いはないという理解で正しいですか
18. IFAへ支払う**手数料の税務上の取扱い**（消費税を含む）を教えてください

## 10. この章のチェックリスト

- [ ] **「口座区分」と「分配金の源泉徴収」は別の話**であることを、設計チーム全員が理解している
- [ ] 一般口座・法人口座でも**分配金は税引後で再投資される**設計になっている
- [ ] 個人と法人の違い（一覧）を要件定義書に転記した

- [ ] スコープ外の法人類型を**受け入れてしまわない制御**を設計した
