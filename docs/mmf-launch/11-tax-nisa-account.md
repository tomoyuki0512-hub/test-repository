# ⑪ 口座・税制・NISA・マイナンバー — 株式投信とは別物として設計する

[← ⑩ ソナー連携・責任分界点](10-sonar-integration.md) ｜ [総合インデックス](README.md) ｜ 次 → [⑫ 証券サイト（フロント）・非機能要件](12-web-nonfunctional.md)

**MMF（公社債投資信託）は、株式投資信託と課税の取扱いが異なります。** 「投信だから既存の処理に乗る」という前提で設計すると、税計算・帳票・NISA判定のすべてが誤ります。本章は、その違いを要件として明文化するための章です。

> ⚠️ **本章の重要な前提**
> 税制は改正されます。また、個別の取扱いには解釈の余地があります。
> **本章は「確認すべき論点の所在」を示すものであり、税率・区分・取扱いの断定的な根拠として使わないでください。**
> 設計に入れる前に、必ず **自社の税務部門または税理士の確認を取り、その回答を要件定義書に根拠として明記** してください。[10節の質問票](#10-税務部門への質問票)をそのまま使えます。

---

## 0. この章のゴール

1. **公社債投信と株式投信の課税上の違い**を、要件として言語化できる
2. **NISA対象外**であることが、設計・表示・運用にどう波及するかを理解する
3. 口座区分ごとの処理の違いを網羅できる
4. 税務部門に確認すべき論点を漏れなく挙げられる

## 1. なぜこの章が独立して必要なのか

```
【よくある誤解】
  「投資信託なんだから、既存の投信の税処理に乗るでしょう」
        ↓
  ✕ 誤り。MMFは「公社債投資信託」で、株式投資信託とは別区分

【何が違うのか】
  ┌────────────────┬──────────────────┬──────────────────┐
  │                │ 株式投資信託      │ 公社債投資信託(MMF)│
  ├────────────────┼──────────────────┼──────────────────┤
  │ 分配金の所得区分 │ 配当所得          │ ★利子所得         │
  │ 交付する通知書   │ 配当系の様式      │ ★利子系の様式     │
  │ NISA            │ 対象（要件を満たす）│ ★対象外           │
  │ 配当控除        │ 適用の余地あり     │ 適用なし          │
  │ 解約・償還差益   │ 譲渡所得等        │ 譲渡所得等（同じ） │
  │ 損益通算        │ 可能              │ 可能              │
  └────────────────┴──────────────────┴──────────────────┘
```

**この違いが波及する先**

| 波及先 | 何が変わるか | 章 |
| --- | --- | --- |
| 銘柄マスタ | 所得区分・税区分の設定値 | [⑩ 4節](10-sonar-integration.md#4-銘柄マスタ登録項目) |

| 顧客帳票 | 交付する通知書の種類・様式 | [② 1-2節](02-customer-documents.md#1-2-税務関係の帳票) |
| サイト表示 | **NISA対象外である旨の明示** | [⑫](12-web-nonfunctional.md) |
| 口座開設フロー | NISA口座での買付を防ぐ制御 | [⑫](12-web-nonfunctional.md) |
| 年間取引報告書 | 記載区分 | [7節](#7-年間取引報告書) |

## 2. 口座区分の整理

### 2-1. 対応する口座区分を決める

| 口座区分 | 第1フェーズでの推奨 | 論点 |
| --- | --- | --- |
| **特定口座（源泉徴収あり）** | ◎ 必須 | 最も標準的。顧客の大半 |
| **特定口座（源泉徴収なし）** | ★要確認 | **分配金を受け入れられるかに制約がある可能性**。[3-3節](#3-3-特定口座源泉徴収なしの論点) |
| **一般口座** | ○ | 対応するなら確定申告用の情報提供が必要 |
| **NISA口座** | ✕ **対象外** | ★[4節](#4-最重要nisa対象外の扱い) |
| 法人口座 | 要判断 | 源泉徴収の扱いが個人と異なる |
| 非居住者 | Out推奨 | 租税条約の考慮が必要 |
| 未成年口座 | 要判断 | 既存の仕組みに準じる |

> 💡 **スコープを絞る判断**：第1フェーズを「個人・特定口座（源泉徴収あり）・一般口座」に限定すると、税務要件が大幅に簡素化されます。法人・非居住者を含めるかどうかは、**想定顧客と収益見込みを踏まえて企画部門と決めてください。**

### 2-2. 口座区分に関する設計項目

| 項目 | 決めること |
| --- | --- |
| 買付時の口座区分の指定 | 注文画面で選択させるか、デフォルトを設定するか |
| デフォルトの口座区分 | 特定口座を持っていればそれを既定にする |
| 口座区分の変更 | 年の途中で変更できるか。変更時の既保有分の扱い |
| **口座区分の訂正** | ★[④ 5-3節](04-order-correction-cancel.md#5-3-訂正パターンと対応)。年をまたぐと極めて困難 |
| 特定口座未開設の顧客 | 開設フローへ誘導するか、一般口座で受け付けるか |

## 3. 課税関係の全体像

> ⚠️ **以下は論点の整理です。税率・区分は必ず税務部門に確認してください。**

### 3-1. 2つの課税イベント

```
【① 分配金を受け取る】
    MMFの収益分配金 → 「利子所得」に区分される
        ↓
    支払時に源泉徴収
        ↓
    特定口座（源泉徴収あり）なら、そこで完結（申告不要を選択可）
    申告分離課税を選択して確定申告することも可能

【② 解約・償還する】
    解約時の差益（解約価額 − 取得費） → 「譲渡所得等」に区分される
        ↓
    申告分離課税
        ↓
    特定口座（源泉徴収あり）なら、口座内で源泉徴収・通算
```

### 3-2. 損益通算

公社債投信は、**上場株式等と同じグループ**で損益通算ができる、という枠組みで整理されています。

| 通算の組合せ | 可否（★要確認） |
| --- | --- |
| MMFの分配金 ⇔ 上場株式の譲渡損失 | 可能とされる |
| MMFの解約損 ⇔ 上場株式の譲渡益 | 可能とされる |
| MMFの解約損 ⇔ 株式投信の分配金 | 可能とされる |
| 上記と、一般公社債等・先物等との通算 | ★別グループ。要確認 |

> 🔍 **確認事項**：特定口座（源泉徴収あり）において、MMFの分配金・解約損益が**他の上場株式等と自動的に通算される**設計になっているか。[⑩](10-sonar-integration.md)の質問22で大和総研にも確認してください。

### 3-3. 特定口座（源泉徴収なし）の論点

> ⚠️ **特定口座には「源泉徴収あり（源泉徴収選択口座）」と「源泉徴収なし（簡易申告口座）」があり、分配金等の受入れについて取扱いが異なる可能性があります。**
>
> 🔍 **税務部門への確認事項**
> - 特定口座（源泉徴収なし）で、MMFの**分配金を口座に受け入れられるか**
> - 受け入れられない場合、分配金はどう処理されるか（一般口座扱いになるのか）
> - その場合、顧客への通知書はどうなるか
>
> **この論点を確認せずに設計すると、特定口座（源泉徴収なし）の顧客で処理が破綻します。**

### 3-4. 法人口座

| 論点 | 内容 |
| --- | --- |
| 源泉徴収の税率 | ★**個人と異なる**。住民税（利子割）相当分の扱いが違う |
| 特定口座 | ★法人は特定口座を利用できない（**一般口座のみ**） |
| **分配金の源泉徴収** | ★**一般口座でも源泉徴収される**（＝税引後で再投資） |
| 通知書 | 法人向けの様式。★**所得税額控除**のための税額通知 |
| 法定調書 | 支払調書の提出 |
| **法人の類型** | ★非課税法人・金融機関等など、**源泉徴収の取扱いが異なる類型がある** |

> ⚠️ **「一般口座だから源泉徴収されない」は誤りです。** 特定口座の「源泉徴収あり／なし」は主に**譲渡損益**の話であり、**分配金（利子等）は口座区分にかかわらず源泉徴収**されます。
> 📖 **法人・IFA口座の詳細は [⑮ 口座種別・チャネル別の取扱い](15-account-types.md) で扱います。** 本節は概要のみです。

> 🔍 **確認事項**：法人口座を取り扱う場合の源泉徴収税率と、ソナーが税率の切替に対応しているか（[⑩](10-sonar-integration.md)の質問23）。詳細な確認項目は[⑮ 9節](15-account-types.md#9-税務部門への追加質問票)。

## 4. 【最重要】NISA対象外の扱い

### 4-1. 前提

**公社債投資信託は、NISA（つみたて投資枠・成長投資枠のいずれも）の対象外**という整理がなされています。

> 🔍 **確認事項**：最新の制度においてMMFがNISAの対象となるか否かを、コンプライアンス・税務部門に確認してください。**制度は改正され得ます。**

### 4-2. 設計への波及（4か所）

対象外であることは、**単に「使えない」で終わりません。** 4か所で明示的な設計が必要です。

| # | 箇所 | 必要な設計 | 漏らすとどうなるか |
| --- | --- | --- | --- |
| **1** | **銘柄マスタ** | NISA対象外フラグの設定 | 税処理・判定が誤る |
| **2** | **注文画面** | NISA口座を選択肢に出さない／選択時にエラー | ★**顧客がNISAで買えてしまう** |
| **3** | **ファンド詳細画面** | 「NISA対象外」の明示 | ★**顧客の誤認・苦情** |
| **4** | **商品検索・絞込み** | 「NISA対象」で絞り込んだときに出てこない | 誤誘導 |

> ⚠️ **箇所2が最も危険です。** 既存の投信買付画面を流用すると、口座区分の選択肢にNISAが残ったままになりがちです。**NISA口座で約定してしまうと、事後の訂正が極めて困難**（NISAの枠の復元、年をまたぐと不可能など）になります。
>
> **必ずテストケースに「NISA口座での買付を試みる」を入れてください。**

### 4-3. 表示の文言

| 場所 | 文言の例 |
| --- | --- |
| ファンド詳細 | 「当ファンドはNISA（つみたて投資枠・成長投資枠）の対象外です」 |
| 注文画面 | 口座区分の選択肢にNISAを表示しない |
| よくある質問 | 「NISAで買えますか？」への回答を用意 |

> 💡 **コールセンターへの想定問答に必ず入れてください。** 「NISAで買えると思っていた」は、リリース直後に最も多く来る問合せのひとつです（[⑬](13-compliance-ops.md)）。

## 5. 取得単価の計算

### 5-1. 2つの「ロット管理」を混同しない

[④ 9節](04-order-correction-cancel.md#9-信託財産留保額とロット管理mmf固有の難所)で扱った**信託財産留保額のロット管理**と、税務上の**取得単価計算**は、**まったく別のロジック**です。

| | 信託財産留保額のロット管理 | 税務上の取得単価 |
| --- | --- | --- |
| 目的 | 短期解約の判定 | 譲渡損益の計算 |
| 根拠 | **信託約款** | **税法** |
| 方式 | 取得日ごとのロット（FIFO等） | 総平均法に準ずる方法など |
| 再投資口の扱い | ★約款による | 取得として平均単価に反映 |

> ⚠️ **この2つを1つのデータ構造で兼用しようとすると、必ず破綻します。** 設計段階で別々に持つことを明確にしてください。

### 5-2. 取得単価の設計項目

| 項目 | 決めること |
| --- | --- |
| **計算方法** | 総平均法に準ずる方法か。★税務部門に確認 |
| 再投資による取得 | 再投資口数を取得として平均単価に反映する |
| **端数処理** | 円未満・小数点以下の処理 |
| **信託財産留保額の扱い** | ★取得費に含めるか、譲渡費用とするか。**要確認** |
| 口座区分をまたぐ場合 | 特定口座と一般口座で別々に管理 |
| 移管時 | 他社からの移管時の取得単価の引継ぎ |

> 🔍 **確認事項**：**信託財産留保額が、税務上どう扱われるか**（取得費への算入／譲渡費用／その他）。MMFは短期解約で留保額が発生しやすいため、**この扱いが譲渡損益の計算に直接影響します。**

## 6. マイナンバー・法定調書

| 項目 | 内容 |
| --- | --- |
| **マイナンバーの取得** | 口座開設時に取得済みのはず。新商品で追加取得は通常不要 |
| **未提出者の扱い** | マイナンバー未提出の顧客が買付できるか。既存ルールに準じる |
| **法定調書** | 支払調書等の提出。**公社債投信の分配金に係る調書の種類を要確認** |
| 調書の作成 | ソナーが標準で作成するか（[⑩](10-sonar-integration.md)の質問34） |
| 提出方法・期限 | 既存の業務フローに乗るか |

> 🔍 **確認事項**：MMFの分配金（利子所得）について提出が必要な法定調書の種類と、提出要件（金額基準など）。**株式投信とは異なる調書になる可能性**があります。

## 7. 年間取引報告書

| 論点 | 内容 |
| --- | --- |
| **記載区分** | MMFの分配金・譲渡損益がどの欄に記載されるか |
| 作成対象 | 特定口座を持ち、当年に取引・分配があった顧客 |
| **作成タイミング** | 年末の処理後。★**12月末の再投資処理の後**である必要がある |
| 交付期限 | 法定期限（翌年1月末が目安。要確認） |
| 訂正版 | 事故訂正が発生した場合の訂正版の発行（[④ 6節](04-order-correction-cancel.md#6-受渡後の誤り事故訂正)） |
| 電子交付 | 電子交付の対象にできるか（[⑥](06-prospectus-delivery.md)） |

> ⚠️ **12月末のバッチ順序に注意してください。**
> ```
>  12月末最終営業日
>    ① 12月分の分配金確定・源泉徴収
>    ② 月末一括再投資
>    ③ 年末残高確定
>    ④ 年間取引報告書の作成    ← ①〜③が終わっていないと作れない
> ```
> この順序が崩れると、年間取引報告書の金額が誤ります。[⑭ テスト](14-test-release.md)で**年末シナリオのテスト**を必ず実施してください。

## 8. 税制改正への追随

| 論点 | 設計 |
| --- | --- |

> 🔍 **大和総研へ**：税制改正時の対応（税率変更・区分変更）は、ソナーの標準保守に含まれますか。個社での対応が必要な範囲はどこまでですか。

## 9. 見落としやすい論点

| 論点 | 内容 |
| --- | --- |
| **相続・贈与** | 相続時の取得単価の引継ぎ、未収分配金の扱い |
| **他社からの移管** | 取得単価・取得日の引継ぎ。信託財産留保額の判定期間はどうなるか |
| **他社への移管** | 引継ぎデータの提供 |
| **口座区分の変更** | 一般口座から特定口座への移管の可否 |
| **年の途中での出国** | 非居住者になった場合 |
| 特定口座の廃止 | 顧客が特定口座を廃止する場合の既保有分 |
| **源泉税の納付** | 月末再投資で発生した源泉税の納付期限管理（[③ 3節](03-internal-documents.md#3-経理会計帳票)） |
| **還付処理** | 損益通算による源泉税の還付 |

## 10. 税務部門への質問票

**そのまま送付できる形にしています。** 回答は要件定義書に根拠として添付してください。

### A. 課税区分

1. MMF（公社債投資信託）の**収益分配金の所得区分**と、適用される源泉徴収税率を教えてください
2. 解約・償還時の差益の所得区分と課税方式を教えてください
3. 上場株式等との**損益通算**の可否と、通算できる範囲を教えてください

### B. 口座区分

4. **特定口座（源泉徴収なし）**で、MMFの分配金を口座に受け入れることは可能ですか。不可の場合、どう処理されますか
5. **法人口座**の場合の源泉徴収税率を教えてください
6. 一般口座の場合、顧客に提供すべき情報は何ですか

### C. NISA

7. MMF（公社債投資信託）は、**現行のNISA制度の対象となりますか**
8. 対象外の場合、サイト上でどのような表示が適切ですか

### D. 取得単価・費用

9. 取得単価の**計算方法**（総平均法に準ずる方法等）を教えてください
10. **信託財産留保額**は、税務上どう扱われますか（取得費／譲渡費用／その他）
11. 分配金の**再投資による取得**は、取得単価にどう反映されますか
12. 端数処理（取得単価・源泉税額）の方法を教えてください

### E. 帳票・調書

13. MMFの分配金について、顧客に交付すべき**通知書の種類と様式**を教えてください
14. 提出が必要な**法定調書**の種類と提出要件を教えてください
15. **年間取引報告書**において、MMFの分配金・譲渡損益はどの欄に記載されますか

### F. 運用

16. 月末再投資で発生した**源泉税の納付期限**と、納付手続を教えてください
17. **口座区分の訂正**は、いつまで可能ですか。年をまたぐ場合はどうなりますか
18. 事故訂正が発生した場合の、**年間取引報告書の訂正版**の発行手続を教えてください
19. 他社からの**移管**時に引き継ぐべき情報は何ですか
20. 税制改正情報の連携ルートを確認させてください
