# 実証実験（PoC）「報告書渡し」の計上基準日 完全ガイド

業務効率化の実証実験（PoC）案件で、**受渡条件を「報告書渡し」にしたとき、計上基準日には何の日付を入れるのか**を、会計基準・法人税・消費税の根拠までさかのぼって整理します。

> **結論から言うと、「報告書を完成させて顧客に引き渡した日（＝顧客が受領した日）」です。**
> 契約に検収条項がある場合だけ「顧客の検収完了日」にズレます。報告書を書き終えた日でも、社内承認日でも、請求日でも、入金日でもありません。

> ⚠️ このページは実務の判断材料をまとめたものです。個別案件の最終的な取扱いは、**必ず自社の監査法人・顧問税理士に確認**してください。

---

## 1. 30秒サマリ

| 契約の書きぶり | 計上基準日に入れる日付 | 主な証憑 |
| --- | --- | --- |
| **検収条項なし（納品のみ）** | **報告書を顧客に引き渡した日（顧客受領日）** | 受領書、送付メール、共有ストレージのDLログ |
| 検収条項あり | 顧客の**検収完了日**（検収書・検収通知の日付） | 検収書、検収通知メール |
| 検収条項あり＋みなし検収 | 検収期間の**満了日**（異議なく経過した日） | 納品記録＋期間満了を示す記録 |

**根拠のコア（会計・税務ともに同じ結論）**

- 会計 … 収益認識会計基準39項「支配の移転」→ 報告書渡しでは**物理的占有の移転**と**顧客の検収**が決め手
- 法人税 … 法人税基本通達2-1-21の7「物の引渡しを要する請負契約 → 目的物の全部を完成して相手方に**引き渡した日**」
- 消費税 … 消費税法基本通達9-1-5 も同じ立て付け → **課税期間の判定も同じ日**

## 2. 今回のケース：請負契約＋検収条項なし

契約類型が**請負**で、契約書に**検収条項がない**（報告書の提出・引渡しで足りる）場合、分岐はありません。

> **計上基準日 ＝ 契約仕様を満たす最終版の報告書を完成させ、顧客に引き渡した日**

法人税基本通達2-1-21の7がそのまま当てはまる直球のケースです。会計上も、収益認識会計基準39項の支配移転指標のうち「**企業が資産の物理的占有を移転したこと**」で判定することになり、**会計と税務でズレが出ません**。これは実務上とても楽な状態です。

### この構成で特に効いてくる注意点

**① 検収条項がない＝「いつ渡したか」の立証責任が自社に寄る**

検収書という日付入りの決定的な証憑が存在しないため、引渡日を後から客観的に示せる記録を必ず残してください。

- 送信日時が残るメール（報告書を添付、または格納先URLを通知）
- 共有ストレージ／ポータルのアップロード日時・顧客側のダウンロードログ
- 受領書（顧客の押印または返信メールでの受領確認）

期末をまたぐ案件では、これが監査・税務調査の**直接の争点**になります。

**② ドラフト提出日は計上基準日ではない**

顧客レビュー → 修正 → 再提出というフローがあるなら、計上基準日は**最終版の引渡日**です。中間ドラフトを渡した日ではありません。「完成して引き渡した」といえるのは最終版です。

**③ 契約不適合責任は残るが、収益認識は妨げない**

請負なので引渡し後も契約不適合責任（旧・瑕疵担保責任）が残ります（民法559条による売買規定の準用、期間制限は民法637条）。ただしこれは**収益認識を先延ばしにする理由にはなりません**。将来の補修見込コストは、必要に応じて別途引当金として処理する論点です。

**④ 形式ではなく実態で見る**

契約書に検収条項がなくても、運用上は「顧客の内容確認・OKを待ってから請求する」のが慣行になっている、というケースはよくあります。この場合、**実質的に支配がいつ移転したか**で判定する必要があります。運用と契約書が食い違っているなら、契約書側を実態に合わせて直すのが本筋です（→ 10章）。

## 3. 用語の整理：受渡条件・計上基準日・売上計上基準

この3つは混同されやすいので、先に関係を押さえます。

| 用語 | 意味 | 例 |
| --- | --- | --- |
| **受渡条件** | 何をどう渡したら「引き渡した」ことになるか、という**契約上の取決め** | 報告書渡し／現地据付渡し／出荷渡し／持込渡し |
| **売上計上基準** | 売上をどのタイミングで計上するかの**会計方針** | 出荷基準／引渡基準／検収基準 |
| **計上基準日** | その方針にもとづいて実際に**帳簿に入れる具体的な日付** | 2026-03-25 |

流れとしてはこうなります。

```
契約で「受渡条件」を決める
        ↓
それに対応する「売上計上基準」が決まる
        ↓
個別案件ごとの「計上基準日」（実際の日付）が決まる
```

つまり **「受渡条件＝報告書渡し」と決めた時点で、売上計上基準は自動的に引渡基準（または検収基準）側に寄る**ということです。出荷基準は物理的なモノの発送を前提にした基準なので、報告書のような成果物にはなじみません。

### 3つの売上計上基準の比較

| 基準 | 計上タイミング | 収益認識基準との相性 | 報告書渡しでの適否 |
| --- | --- | --- | --- |
| **出荷基準** | 商品を出荷した時点 | 国内販売の代替的取扱いとして容認（適用指針98項） | ✕ モノの販売向け。報告書には使わない |
| **引渡基準** | 顧客に引き渡した時点 | ○ 支配移転の考え方と整合 | **◎ 検収条項がない場合の本命** |
| **検収基準** | 顧客が検収した時点 | ○ 支配移転指標(5)そのもの | **◎ 検収条項がある場合の本命** |

## 4. 結論：報告書渡しの計上基準日（パターン別）

### パターンA：検収条項なし（納品のみ）← 今回のケース

**計上基準日 ＝ 報告書の引渡日（顧客受領日）**

- 電子納品なら、顧客がアクセスできる状態にし、その旨を通知した日
- 紙・対面納品なら、実際に手渡した日（受領書の日付）
- 郵送なら、到達日（＝顧客が受領した日）。発送日ではない点に注意

### パターンB：検収条項あり

**計上基準日 ＝ 顧客の検収完了日**

- 検収書の日付、または検収完了通知メールの受信日
- 納品日と検収日が別の日なら、**検収日**が計上基準日

### パターンC：検収条項あり＋みなし検収

**計上基準日 ＝ 検収期間の満了日**

- 「納品後10営業日以内に異議がなければ検収されたものとみなす」型
- 顧客から異議なくその期間が経過した日
- 期間内に顧客が明示的に検収した場合は、その検収日が優先

### 計上基準日にしてはいけない日

| ✕ 使わない日 | なぜダメか |
| --- | --- |
| 報告書の作成完了日 | 社内で書き終えただけ。顧客に何も移転していない |
| 社内承認日（上長決裁日） | 完全に自社の内部事情。顧客とは無関係 |
| 報告会・成果報告プレゼンの実施日 | 報告書の引渡しと報告会は別物。契約上の成果物が報告書なら、報告書の引渡しで判定 |
| 請求書の発行日 | 請求は収益認識の結果であって原因ではない |
| 入金日 | 現金主義。発生主義・実現主義に反する |
| 契約書上の「完了予定日」 | 予定は予定。実際にいつ渡したかで判定 |

## 5. なぜそうなるか① 会計（収益認識に関する会計基準）

### 5-1. 適用される基準

**企業会計基準第29号「収益認識に関する会計基準」**（2018年3月30日公表、2020年3月31日改正）と、**企業会計基準適用指針第30号**。原則として2021年4月1日以後開始する事業年度の期首から強制適用されています（上場企業、会社法上の大会社など。中小企業の扱いは13章）。

### 5-2. 5つのステップ

| ステップ | 内容 | PoC案件での中身 |
| --- | --- | --- |
| Step1 | 契約の識別 | PoC業務委託契約 |
| Step2 | 履行義務の識別 | 「実証実験を行い報告書を提出する」＝通常は1つの履行義務 |
| Step3 | 取引価格の算定 | 契約金額。成功報酬があれば変動対価の検討（→ 12章） |
| Step4 | 履行義務への配分 | 履行義務が1つなら配分不要 |
| **Step5** | **履行義務の充足による収益の認識** | **← ここが「計上基準日」の話** |

### 5-3. Step5の判定フロー

```
        ┌─────────────────────────────────────┐
        │ 基準38項：一定の期間にわたり充足？    │
        │  ① 履行につれ顧客が便益を享受        │
        │  ② 生成・増価する資産を顧客が支配    │
        │  ③ 他に転用できない資産             │
        │     ＋完了部分の対価を収受する       │
        │       強制力のある権利               │
        └─────────────────────────────────────┘
              │                     │
      いずれか満たす            すべて満たさない
              │                     │
              ▼                     ▼
     一定の期間にわたり        ┌──────────────────────┐
     収益を認識（進捗度）      │ 基準39項：一時点で充足 │
                              │ 支配移転の5指標で判定  │
                              └──────────────────────┘
                                        │
                                        ▼
                              報告書を引き渡した日
                              （検収条項があれば検収日）
```

### 5-4. なぜPoCは「一時点」になるのか

38項の3要件を、PoC案件に当てはめて検証します。

| 要件 | PoC案件での判定 | 理由 |
| --- | --- | --- |
| ① 履行につれ顧客が便益を享受し、同時に消費する | ✕ | 清掃・警備のような日常反復サービスと違い、検証結果は報告書として渡されるまで顧客は便益を得られない |
| ② 生成・増価する資産を顧客が支配 | ✕ | 作成途中の報告書を顧客が支配しているとはいえない |
| ③ 他に転用できない資産＋完了部分の対価を収受する強制力のある権利 | **△→✕** | 顧客専用の検証報告書なので「他に転用できない」は満たしやすい。しかし**「完了部分について対価を収受する強制力のある権利」を欠くことが多い**ため、要件全体としては満たさない |

**③がポイントです。** 契約書に「顧客都合で中途解約した場合、それまでの履行部分に対応する対価＋合理的な利益マージンを支払う」旨の条項があれば③を満たす可能性がありますが、通常のPoC契約にはこうした条項がありません。中途解約時は実費精算どまり、あるいは規定なし、というのが一般的です。

→ **3要件すべてを満たさない ⇒ 一時点で充足される履行義務**

> 💡 逆にいうと、③のような条項を契約に入れると期間按分（進捗度に応じた収益認識）になりうる、ということです。契約書の書きぶりが会計処理を決めます。

### 5-5. 一時点の場合：支配移転の5指標（基準39項）

一時点で充足される場合、資産に対する支配が顧客に移転した時点を、次の5つの指標を考慮して判定します。

| # | 指標 | 報告書渡しPoCでの当てはめ |
| --- | --- | --- |
| (1) | 企業が資産に関する対価を収受する現在の権利を有していること | 引渡し後に請求権が発生する契約が多い |
| (2) | 顧客が資産に対する法的所有権を有していること | 報告書の所有権・著作権の移転時期を契約で確認 |
| (3) | **企業が資産の物理的占有を移転したこと** | **★ 引渡し（納品）そのもの。今回の決め手** |
| (4) | 顧客が資産の所有に伴う重要なリスク・経済価値を有していること | 報告書を受け取れば、その内容を使うのは顧客 |
| (5) | **顧客が資産を検収したこと** | **★ 検収条項がある場合の決め手** |

これらは**すべてを満たす必要はなく**、総合的に判断する「指標」です。報告書渡しのPoCでは(3)と(5)がほぼ決定的に効きます。

### 5-6. 検収の扱い（適用指針80〜83項）

適用指針80項以下では、顧客の検収について次のように整理されています。

- 顧客が資産を検収したことは、顧客がその資産の使用を指図し、残りの便益のほとんどすべてを享受する能力を獲得したことを示す可能性がある
- ただし、**検収の内容が客観的で比較的単純な場合**（所定の大きさや重量に適合するかの確認など）は、企業は検収前に適合性を判断でき、**検収前に支配が移転したと判断できる場合がある**
- 過去の同種取引の実績により、合意された仕様への適合を客観的に示せる場合も同様

**PoCの報告書はどうか？**

PoCの報告書は「検証結果の内容そのもの」が成果です。大きさや重量のような形式的・客観的な確認ではなく、**顧客が内容を読んで初めて価値を判断できる**性質のものです。したがって、検収条項がある場合は「形式的な検収だから検収前に支配移転」とは主張しにくく、**実質的な検収をもって支配移転**と考えるのが自然です。

逆に、**検収条項がない今回のケースでは、引渡しをもって支配が移転した**と整理することになります。

## 6. なぜそうなるか② 税務（法人税・消費税）

### 6-1. 法人税

**法人税法22条の2**（平成30年度税制改正で新設）が基本ルールです。

| 項 | 内容 |
| --- | --- |
| 第1項 | 資産の販売等に係る収益の額は、**目的物の引渡し又は役務の提供の日**の属する事業年度の益金の額に算入する |
| 第2項 | 一般に公正妥当と認められる会計処理の基準に従って**引渡し等の日に近接する日**の属する事業年度の収益として経理した場合は、その事業年度の益金に算入する |
| 第3項 | 上記により経理した場合、申告調整による収益計上時期の変更は認められない |

そのうえで、**法人税基本通達2-1-21の7（請負に係る収益の帰属の時期）**が請負契約について具体的に定めています。

> **物の引渡しを要する請負契約** … その目的物の**全部を完成して相手方に引き渡した日**
> **物の引渡しを要しない請負契約** … その約した**役務の全部を完了した日**

**「受渡条件＝報告書渡し」は、報告書という成果物を引き渡す契約なので、前者（物の引渡しを要する請負契約）に該当します。したがって「引渡日」です。**

なお、同通達には、履行義務が一定の期間にわたり充足されるもの（法人税基本通達2-1-21の4の(1)〜(3)のいずれかを満たす場合）について、2-1-21の5に準じて算定した額を各事業年度の益金に算入しているときはこれを認める、という例外も置かれています。これは会計側の38項と揃えた作りです。

### 6-2. 消費税

**消費税法基本通達9-1-5（請負による資産の譲渡等の時期）**も、法人税とまったく同じ立て付けです。

> 物の引渡しを要する請負契約にあってはその**目的物の全部を完成して相手方に引き渡した日**、物の引渡しを要しない請負契約にあってはその約した**役務の全部を完了した日**

つまり、**どの課税期間の売上として消費税を申告するかも、同じ「引渡日」で判定します。**

### 6-3. インボイス（適格請求書）との関係

適格請求書の記載事項には「**取引年月日**」があります。ここに入れる日付も、原則として引渡日（＝計上基準日）と揃えます。計上基準日とインボイスの取引年月日がズレていると、税務調査で「なぜズレているのか」を必ず聞かれます。

### 6-4. 会計と税務のズレはあるか

**今回のケース（請負＋検収条項なし・一時点）では、ズレません。**

| | 判定日 |
| --- | --- |
| 会計（収益認識基準39項） | 支配移転日＝報告書の引渡日 |
| 法人税（基通2-1-21の7） | 目的物を完成して引き渡した日 |
| 消費税（消基通9-1-5） | 目的物を完成して引き渡した日 |

3つとも同じ日になるので、申告調整も税効果の一時差異も発生しません。

### 6-5. 継続適用が必要

一度採用した売上計上基準は、**継続して適用する**必要があります。案件ごとに「今回は引渡基準、次回は検収基準」と使い分けることは、利益操作とみなされるおそれがあるため認められません。合理的な理由なく変更した場合、税務調査で否認されるリスクがあります。

## 7. 契約類型別の分岐（請負／準委任）

「報告書渡し」という受渡条件を選べるかどうかは、契約類型に依存します。

| 契約類型 | 根拠条文 | 報酬の対象 | 収益認識 | 計上基準日 |
| --- | --- | --- | --- | --- |
| **請負** | 民法632条 | 仕事の**完成** | 一時点 | **引渡日**（検収条項があれば検収日） |
| **準委任・成果完成型** | 民法648条の2 | 業務により得られる**成果** | 一時点（実質的に請負と同じ扱い） | **引渡日**（検収条項があれば検収日） |
| **準委任・履行割合型** | 民法648条 | **作業時間・工数** | 一定の期間にわたり充足の可能性 | 期間按分（月末など） |

### 判定フロー

```
契約書を読む
  │
  ├─ 「報告書を完成させて納品する」義務が書いてある？
  │     └─ YES → 請負 or 成果完成型準委任
  │               → 受渡条件「報告書渡し」が成立
  │               → 計上基準日 = 引渡日（or 検収日）
  │
  └─ 「◯人月を投入して作業する」「稼働時間に応じて報酬」？
        └─ YES → 履行割合型準委任
                  → そもそも「報告書渡し」は受渡条件になじまない
                  → 期間按分を検討すべき
```

### 請負と成果完成型準委任の違い

2020年4月1日施行の改正民法で、準委任契約に「成果完成型」が追加されました。報告書の引渡しに対して報酬が発生する点は請負と同じですが、**「仕事を完成させる義務」を負うかどうか**が違います。

| | 請負 | 成果完成型準委任 |
| --- | --- | --- |
| 完成義務 | **あり**（完成しなければ報酬なし） | なし（善管注意義務は負う） |
| 契約不適合責任 | あり | 原則なし |
| 収益認識の考え方 | 完成・引渡しで一時点 | 成果の引渡しで一時点 |

会計上の計上基準日の結論は**どちらも引渡日**で変わりませんが、**実証実験が「不成功」に終わったときの報酬の有無**が変わります（→ 12章）。

> 💡 特許庁のオープンイノベーション向けモデル契約書では、PoC契約は「一定の成果物を完成させるもの（請負型）ではなく、検証のための業務の実施を目的とした**準委任型**」を前提に作られています。自社契約がどちらなのかは、契約書の文言で確認してください。

| 11 | 中間報告書は最終報告書の一部（独立した価値なし） | 履行義務は1つ。**最終報告書の引渡日**に一括 |
| 12 | 履行割合型準委任（人月精算） | 月末など、**期間按分**の各時点 |

## 9. 期末をまたぐときのカットオフ

期末をまたぐ案件は、**最も間違えやすく、最も指摘されやすい**論点です。

### 具体例：3月決算の会社

| 出来事 | 日付 |
| --- | --- |
| 報告書の作成完了（社内） | 3月28日 |
| 顧客へメールで納品 | **3月31日** |
| 顧客からお礼の返信 | 4月3日 |
| 請求書発行 | 4月10日 |
| 入金 | 4月30日 |

**検収条項なし（今回のケース）→ 計上基準日は 3月31日 ＝ 当期の売上**

引渡しは3月31日に完了しています。顧客の返信は受領の証跡としては有用ですが、返信日が計上基準日になるわけではありません。

**もし検収条項があり、検収書の日付が4月3日だった場合 → 翌期の売上**

同じ納品日でも、契約に検収条項があるだけで期が変わります。**これが「受渡条件を契約でどう書くか」が経営上の意味を持つ理由**です。

### 期末前後にやるべきこと

- 期末日直前の納品は、**送信日時のわかる形**で記録を残す（メールのタイムスタンプ、ログのエクスポート）
- 「3月中に納品したことにしてほしい」という依頼は**絶対に受けない**。実際の引渡日で計上する
- 期末をまたぐ案件のリストを作り、1件ずつ引渡日と証憑を確認する
- 未引渡しの案件に発生した原価は、**仕掛品（未成業務支出金）**として資産計上し、収益と対応させる

### 期ズレが起きたときの影響

| 誤り | 影響 |
| --- | --- |
| 翌期の売上を当期に計上（前倒し） | 当期利益の過大計上。法人税・消費税の過大納付。監査上は**期ズレの指摘対象** |
| 当期の売上を翌期に計上（先送り） | 当期利益の過少計上。税務調査で**売上除外**と見られるリスク |

前倒し・先送りのどちらも問題です。「多めに払っているからいいだろう」は通用しません。

## 10. 必要な証憑と社内運用

### 10-1. 検収条項がない場合の引渡日の立証（今回のケース）

検収書という決定的な証憑がないぶん、次のいずれか（できれば複数）を残します。

| 証憑 | 強さ | 備考 |
| --- | --- | --- |
| 顧客からの受領確認メール | ★★★ | 「受領しました」の一言でも効果は大きい |
| 受領書（顧客の押印・署名） | ★★★ | 検収書に準じる強さ。日付欄を必ず記入 |
| 共有ストレージの顧客側ダウンロードログ | ★★☆ | 顧客がアクセスした事実を示せる |
| 報告書を添付した送信メール | ★★☆ | 自社側の記録だが、タイムスタンプは有効 |
| 納品書（自社発行） | ★☆☆ | 自社側の一方的な記録。単独では弱い |

**運用のコツ：納品メールに一文添える**

> 「本メールをもって成果物の納品とさせていただきます。ご確認のうえ、受領のご返信をいただけますと幸いです。」

これだけで、返信が受領の証跡になります。手間もコストもゼロです。

### 10-2. 受領書に入れておきたい項目

- 契約名・契約番号
- 成果物名（例：「◯◯業務効率化実証実験 報告書 v1.0」）
- **受領日**（← 最重要）
- 受領者（顧客側の担当部署・氏名）
- 押印または署名

### 10-3. 次回以降、検収条項を入れるべきか

**検収条項を入れるメリット**

- 検収書という日付が明確な証憑が手に入る
- 「いつ支配が移転したか」の争いがなくなる
- 監査・税務調査で説明が容易

**検収条項を入れるデメリット**

- 顧客が検収を渋ると、収益認識が遅れる（期をまたぐリスク）
- 検収基準を採用すると、以後は継続適用が必要

**推奨：みなし検収付きの検収条項**

> 「乙は成果物を甲に納入する。甲は納入後10営業日以内に検収を行い、検収結果を乙に通知する。当該期間内に甲から書面による異議の通知がない場合、当該期間の満了をもって検収が完了したものとみなす。」

これなら、検収書という明確な証憑が得られつつ、顧客が検収を放置しても収益認識が無限に遅れることはありません。**実務上のバランスが最も良い形**です。

### 10-4. 販売管理システムへの入力

多くの販売管理システムでは、受注登録時に「受渡条件」「計上基準日」を入力します。

- **受渡条件** … 契約に合わせて「報告書渡し」を選択
- **計上基準日** … 納品前は契約上の**予定日**を仮入力し、**実際の引渡し後に実績日に更新する**運用にする

予定日のまま放置して月次を締めてしまうのが、期ズレの典型的な発生源です。**「納品したら計上基準日を実績に直す」を締め処理のチェック項目に入れてください。**

## 11. よくある間違い5選

| # | 間違い | なぜダメか | 正しくは |
| --- | --- | --- | --- |
| 1 | **報告書の作成完了日**で計上 | 社内で書き終えただけで、顧客には何も移転していない | 顧客に引き渡した日 |
| 2 | **報告会の実施日**で計上 | 報告書の引渡しと報告会は別。契約上の成果物が報告書なら報告書で判定 | 報告書の引渡日（報告会が別個の履行義務なら別途配分） |
| 3 | **請求書の発行日**で計上 | 請求は収益認識の結果。原因ではない | 引渡日で計上し、請求はその後 |
| 4 | **入金日**で計上 | 現金主義。発生主義・実現主義に反する | 引渡日で計上し、入金は債権の回収 |
| 5 | **社内承認日**で計上 | 完全に自社の内部プロセス。顧客と無関係 | 顧客への引渡日 |

### 番外：案件ごとに基準を変える

「今回は期末が近いから引渡基準、次は検収基準」——これは**継続性の原則違反**です。利益操作とみなされ、税務調査での否認リスクがあります。基準は社内で統一し、文書化してください。

## 12. PoC特有の論点

### 12-1. 中間報告書がある場合：履行義務は1つか複数か

Step2（履行義務の識別）の話です。

| 状況 | 履行義務 | 収益認識 |
| --- | --- | --- |
| 中間報告書は最終報告書の途中経過にすぎず、それ単独では顧客に価値がない | **1つ** | 最終報告書の引渡日に一括 |
| 中間報告書だけでも顧客が意思決定に使える（フェーズごとに独立した価値がある）／中間報告書に対して独立した対価が定められている | **複数** | それぞれの引渡日に分割計上 |

判定の軸は「**その成果物が単独で顧客にとって便益をもたらすか（別個の財又はサービスか）**」です。契約金額が中間・最終で分けて定められていれば、複数の履行義務である可能性が高くなります。

### 12-2. 成功報酬・変動対価

「実証実験で◯%以上の効率化が確認できた場合、追加報酬を支払う」といった条項がある場合、Step3（取引価格の算定）で**変動対価**として扱います。

- 変動対価は、**最頻値法**または**期待値法**で見積もる
- ただし、**変動対価の額に関する不確実性が事後的に解消される際に、計上した収益の著しい減額が発生しない可能性が高い部分に限り**、取引価格に含める（収益認識基準54項）
- 成果連動の要素が強く見積りが困難なら、**確定するまで取引価格に含めない**判断が保守的

### 12-3. 実証実験が「不成功」に終わった場合

これはPoC特有の重要論点です。

| 契約類型 | 検証結果が芳しくなかった場合 |
| --- | --- |
| **請負** | 「仕事の完成」＝報告書の完成。**検証結果が期待どおりでなくても、契約仕様を満たす報告書を完成・引渡しすれば履行義務は充足**。報酬は発生し、引渡日で収益認識 |
| **成果完成型準委任** | 同上。成果＝報告書の引渡しなので、内容が期待外れでも報酬は発生 |
| **成果連動型の特約付き** | 「効果が確認できなければ報酬なし」等の条項があれば、変動対価・返金義務の検討が必要 |

**「実証実験だから成功しないと売上にならない」は誤解**です。契約上の成果物が報告書である以上、報告書を引き渡せば履行義務は充足します。「検証の結果、期待した効果は確認できなかった」という報告書も、立派な成果物です。

### 12-4. 契約資産・契約負債・前受金

| 状況 | 勘定科目 |
| --- | --- |
| 着手金・前受金を受領したが未納品 | **契約負債**（旧・前受金） |
| 収益を認識したが、請求権がまだ法的に確定していない | **契約資産** |
| 収益を認識し、請求権も確定した | **売掛金** |
| 未納品の案件に発生した原価 | **仕掛品（未成業務支出金）** |

「引渡し前に着手金をもらっている」ケースは実務上よくあります。着手金は受領時点では収益ではなく**契約負債**で、引渡日に収益へ振り替えます。

### 12-5. 契約不適合責任と引当

請負契約では引渡し後も契約不適合責任が残ります（民法559条による準用、民法637条の期間制限＝不適合を知った時から1年以内の通知）。ただし、これは収益認識を遅らせる理由にはなりません。将来の補修見込コストが合理的に見積もれ、かつ金額に重要性があるなら、**引当金**として処理します。

## 13. 中小企業の場合

収益認識に関する会計基準の**強制適用対象**は、上場企業・会社法上の大会社・金商法適用会社などです。それ以外の中小企業（会計監査人を置かない会社）は、**従来どおり企業会計原則の実現主義**によることも認められています。

ただし、結論はほぼ変わりません。

| | 中小企業の実務 |
| --- | --- |
| 会計 | 企業会計原則の実現主義 → 財貨・役務の提供＋対価の受領（またはその確実性）→ **引渡日** |
| 法人税 | **法人税基本通達2-1-21の7が適用される**（会社規模を問わない）→ **引渡日** |
| 消費税 | **消費税法基本通達9-1-5が適用される**（同上）→ **引渡日** |

**税法は会社規模で変わらない**ので、いずれにせよ引渡日で計上するのが正解です。「中小企業だから収益認識基準は関係ない」と考えても、税務上の結論は同じになります。

## 14. 導入前チェックリスト

### 契約の確認

- [ ] 契約類型は請負か、準委任（成果完成型／履行割合型）か
- [ ] 成果物が「報告書」と明確に定義されているか
- [ ] 検収条項はあるか。あるなら検収期間は何日か
- [ ] みなし検収の定めはあるか
- [ ] 中間報告書と最終報告書がある場合、それぞれに独立した対価が定められているか
- [ ] 成功報酬・成果連動の条項はあるか（→ 変動対価の検討）
- [ ] 中途解約時の対価の定めはあるか（→ 38項③の判定に影響）
- [ ] 報告書の著作権・所有権の移転時期はいつか

### 社内ルール・システム設定

- [ ] 売上計上基準が社内で文書化され、継続適用されているか
- [ ] 販売管理システムの「受渡条件」に該当する選択肢があるか
- [ ] 計上基準日を**予定日から実績日に更新する**運用が締め処理に組み込まれているか
- [ ] 期末をまたぐ案件のリスト化と個別確認のプロセスがあるか

### 証憑

- [ ] 引渡日を客観的に示せる証憑が残る運用になっているか
- [ ] 納品メールに受領確認を促す一文が入っているか
- [ ] 受領書・検収書のフォーマットに**日付欄**があるか
- [ ] 電子納品の場合、ログの保存期間が十分か

### 確認先

- [ ] 監査法人に、当該案件の収益認識時点について事前相談したか
- [ ] 顧問税理士に、法人税・消費税の帰属時期を確認したか
